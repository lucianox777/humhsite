📈 Validador EHT - Entropia Harmônica para Trading

Análise científica da percepção coletiva do mercado usando a teoria HUMH

🎯 O que é EHT (Entropia Harmônica para Trading)?

EHT = 1 - |2p - 1| [ℋ] onde p = percepção coletiva de que o preço subirá

Nota: EHT é medida EH (ℋ). O custo operacional (tempo de decisão, spreads) é medido em unidades reais conforme o domínio.

  • EHT < 0.3: Consenso forte - direção clara (momento ideal para trade)
  • EHT 0.3-0.6: Consenso moderado - operar com cautela
  • EHT > 0.6: Alta incerteza - evitar posições grandes
